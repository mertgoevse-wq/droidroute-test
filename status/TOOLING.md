## How to use this inventory

1. Pick the skill that matches the workstream, not the one with the nicest name.
2. Prefer a project skill for project rules, a global skill for technique.
3. Use at least two skills per task in parallel (implementation + verification).
4. If nothing fits, search for one before writing your own: `npx skills find <query>`.
5. Record substitutions in the task log: `skill-substitution: <old> -> <new> (<reason>)`.

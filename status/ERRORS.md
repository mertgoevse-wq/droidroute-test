# Errors & Blockers

Open and resolved problems. The chain stops when an entry is `open` and blocks the next task — see `AGENTS.md` §9.

## Format

```
## <timestamp> — <short title>
- status: open | resolved | accepted-risk
- task: T-0xx
- symptom: what was observed, with the exact command or log line
- cause: what actually caused it (or "unknown, investigating")
- action: what was done or is planned
- evidence: log file / command output location
```
